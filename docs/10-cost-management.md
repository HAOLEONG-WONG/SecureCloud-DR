# Cost Management

## Subscription
- Azure for Students, $100 credit / 12 months

## Cost Control Practices
- VM manually stopped (deallocated) after every work session
- Auto-shutdown not available in Malaysia West region — relying on manual stop as primary control
- Standard SSD disk chosen over Premium to reduce idle storage cost
- Credit usage tracked via Azure Education Hub (Cost Management Budgets not supported for this subscription type)

## Known Costs
- VM (B2ats_v2): ~US$0.0107/hr (~$7.70/month if run continuously — mitigated by stopping when idle)
